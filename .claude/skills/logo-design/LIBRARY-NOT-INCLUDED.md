# Logo library not included

This copy of `logo-design` (kaankiziltug/logo-design-skill@0ecf52e, MIT) omits
`assets/library/svg/`: 1,432 third-party logos that are trademarks of their
owners and are not covered by the MIT license. This repo is public, so they are
not redistributed here.

`classifications.json` and the catalog are kept, so library search still returns
names and labels. To view the logo files, clone the upstream repo locally:
https://github.com/kaankiziltug/logo-design-skill
