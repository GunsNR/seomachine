# Vendor Capability Matrix: Rank Logic Growth OS

Retrieved: 2026-11-03. Sources: official vendor documentation and pricing pages only. Where a page shows its own last-updated date, that date is given as well.
Evidence labels: **Verified** means the official page was fetched today and the claim was read from it. **Unverified** means the page could not be fetched, or the claim could not be found on the fetched page.

## Summary (most decision-relevant)

1. **One aggregator covers most publishing.** ContentStudio has a public REST API (X-API-Key) that posts to 11 networks: FB, IG, LinkedIn, X, TikTok, YouTube, Pinterest, Threads, Bluesky, GBP and Telegram. It costs $15/mo on the API plan, or comes with any paid plan, at 1.5k–7.5k requests/mo. Analytics via the API cover only FB, IG and YouTube. This avoids the Meta, LinkedIn and TikTok app reviews in the MVP.
2. **Going direct to social networks requires review.** Meta needs App Review, Business Verification and Advanced Access for accounts you don't own or manage. LinkedIn org posting is a "Vetted Product", and its Development tier is capped at 500 calls/app/24h. Unaudited TikTok clients can post only `SELF_ONLY`, for at most 5 users per 24h.
3. **YouTube policy changed yesterday.** Unverified API projects are "no longer restricted to private viewing mode" (revision entry dated 2026-11-02). `videos.insert` now has its own bucket: 100 calls/day by default, at 1 unit per call. This reverses the July-2020 audit rule. Confirm it again before building on it.
4. **The analytics/CRM core works on standard accounts.** GSC (Search Analytics, plus URL Inspection read-only at 2,000/day per site), GA4 Data API (200k core tokens/property/day on Standard) and HighLevel API v2 (contacts, opportunities, calendars; Basic API on Starter $97 and Unlimited $297) can all be adapters now.
5. **Some operations need a person.** The Search Console API cannot request indexing. GBP posting needs an approved access application (GBP verified for 60+ days, plus a website), and product posts are not supported. WhatsApp Status and Channels have no documented API. WhatsApp Groups need an Official Business Account and allow at most 8 participants.

## Conflicts / unverifiable

- **HighLevel plan naming.** One extraction of gohighlevel.com/pricing labelled the $497 tier "Founder". A second extraction of the same page, and the help-centre article, call it "Agency Pro". The page may show a promotional label. The price ($497) is consistent across all three.
- **HighLevel plan requirements are not on the developer portal.** The plan-to-API mapping comes from the help centre and the pricing page only. marketplace.gohighlevel.com/docs does not mention plans. Rate limits (100/10 s, 200k/day) also come from the help centre.
- **ContentStudio request quotas.** The /social-media-api page says the API plan includes "3,000 API requests per month by default". The pricing page gives each plan a different allowance (Standard 1,500; Agency 7,500). Analytics-via-API is stated only on /social-media-api, not on /pricing. I did not fetch docs.contentstudio.io directly; endpoint detail comes from search excerpts of that site.
- **YouTube.** The `videos.insert` page and the revision history (entry 2026-11-02) say unverified projects are no longer locked to private. The same revision history still carries the 2020-07-28 entry, which is historical. The change is one day old, so re-check it before build. I did not check whether Google OAuth app verification for the upload scope adds separate friction.
- **Ahrefs eligibility.** The docs say "eligible paid plans", and the pricing page lists API access from Lite upward. ahrefs.com/api, however, offers to "Try API endpoints without an Enterprise plan", which suggests full access may still be Enterprise-only. I could not confirm the monthly API-unit allowance per plan; only "Ahrefs Connect" integration units are listed.
- **GA4 thresholding and sampling fields.** The ResponseMetaData reference page fetched today returned only `dataTruncation*` fields. I could not confirm `subjectToThresholding` or `samplingMetadatas` descriptions from it. Only the quotas-page thresholding note is verified.
- **WhatsApp Status and Channels.** No official documentation of API support was found. A Meta community-forum answer (not official docs) says the Cloud API cannot post to Channels. Treat both as unsupported until Meta documents them.
- **WhatsApp Groups.** The facts come from the search-result excerpt of the official page (updated 2026-10-15), not from a full page fetch. A community thread says sandbox/test numbers are ineligible; that is not confirmed in official docs.
- **TikTok.** WebFetch could not resolve developers.tiktok.com (network allowlist), and Firecrawl does not support the site. The content was read with Tavily extract from the official URLs. No last-updated date was visible.
- **Meta Pages publishing rate limits** are not stated on the Posts or permission pages fetched.
- **LinkedIn Standard tier.** "No restrictions" is as stated; per-endpoint throttles were not checked. Standard-tier approval criteria beyond the screen recording are not detailed on the pages fetched.
